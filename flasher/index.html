Install your local firmware package

The firmware file stays in your browser. Nothing is uploaded to a server. Only SLOOP/Felucca-format FM1_9xx packages are accepted. A matching product marker alone does not guarantee a safe firmware image: only flash a trusted, tested package.

Before flashing, back up projects and samples using the SLOOP web editor. Use a USB data cable and keep the FM1 connected until the update finishes. Recovery may require USB rescue or a hardware programmer.

Technical log








Requirements: Chrome or Edge on a desktop OS with Web MIDI SysEx permission and a connected M-VAVE FM1. If the FM1 is already in SLOOP's OTA mode, the updater attempts to resume. An unsupported or foreign bootloader is rejected.
