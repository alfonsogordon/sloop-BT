No hardware MIDI input connected

This is a controller-test simulator, not a Bluetooth connection or firmware flasher. The FM1 is not changed and no MIDI is sent to it. Use SMC-Mixer DAW/Mackie mode when testing real MIDI input.

Eight physical mixer strips

Strips 1–3: synth tracks. Strip 4: whole drum bus. Strips 5–8: kick, snare, closed hat and clap by default; you can reassign these to any of SLOOP's sixteen drum lanes. Faders use soft pickup when external MIDI input is connected.
